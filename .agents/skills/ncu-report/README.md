# ncu-report

Start with [SKILL.md](SKILL.md) for scope and an example. Use the numbered
references only for the question at hand; [scripts](scripts/README.md) provide
report queries and a standalone harness template.

## Provenance

The generic reference material and helpers derive from
[mit-han-lab/ncu-report-skill](https://github.com/mit-han-lab/ncu-report-skill)
(MIT; [LICENSE](LICENSE) retained). This copy adds H100/sm90 metric vocabulary,
Hopper diagnosis patterns and version-tolerant Python report parsing. The B200
reference and Blackwell companion remain available for reports from those GPUs.
Machine setup, permissions and job submission are user-local responsibilities.
